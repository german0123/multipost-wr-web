## Mantenimiento
Antes de publicar cambios:
1. Comprobar que los enlaces internos apuntan a páginas existentes.
2. Revisar que las descripciones de funciones coinciden con las funciones realmente disponibles.
3. Revisar las políticas legales cuando cambien proveedores, integraciones o tratamientos de datos.
4. Confirmar el resultado del despliegue en GitHub Actions.

Las integraciones con plataformas externas dependen de sus propias autorizaciones, permisos y revisiones. La presencia de una plataforma en la web no implica que la integración esté aprobada o disponible para todos los usuarios.
